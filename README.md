# Portofolio Kebidanan — Ria Dei Mita, A.Md.Keb

Website portofolio profesional untuk **Ria Dei Mita, A.Md.Keb**, lulusan **Diploma III Kebidanan** dari **Politeknik Cendrawasih Palu** (2025).

## Bagian Portofolio
- **Beranda (Hero):** Perkenalan singkat, gelar `A.Md.Keb`, tautan media sosial, dan akses CV.
- **Tentang Saya:** Profil singkat dan latar belakang pelayanan kebidanan.
- **Pengalaman Praktik:** 6 bidang asuhan kebidanan klinis (ANC, Bersalin, Nifas, Bayi Baru Lahir, KB, dan Kesehatan Reproduksi Perempuan).
- **Kompetensi:** Keterampilan klinis kebidanan dan komunikasi pasien.
- **Riwayat Pendidikan:** Timeline pendidikan dari SMP hingga D-III Kebidanan.
- **Karya & Proyek:** Karya Tulis Ilmiah (KTI) dan program asuhan kebidanan.
- **Kontak:** Formulir pesan, email, nomor telepon, lokasi, dan media sosial.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
